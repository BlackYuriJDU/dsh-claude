# @deepseek-ai/dsh-client-ui-handoff

[English](README.md) | 中文

交接插件：**Artifacts** 模态框。浏览器侧在框架级的 `shell.overlay` slot 中放置一个宿主组件，在侧边栏的 **Artefatos** 行派发 `dshc:sidebar-design` window 事件之前，它保持为空。随后模态框读取当前会话由 `ui-deliverables` 发布的 `deliverables` 轮次数据，按最新轮次在前列出每个轮次产出的文件，并在同一轮次内去重。点击文件时，先把相对路径解析到会话 cwd，再通过 Host 路径打开器打开。没有当前会话或没有产出文件时，模态框显示空状态。

Node 侧不执行任何操作：模态框只读取浏览器侧的对话数据，面向模型的文件引用指引归 `ui-deliverables` 所有。

## 模型体验

无。该包只展示其他插件已经记录的文件；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **只有文件，没有 artifact 对象**：模态框列出产出的工作区文件；它没有预览、版本历史或导出功能，从未成为文件的内容不会出现。
- **仅限当前会话**：不汇总其他会话或项目中的文件。
